# Security

permlock reads untrusted code: every file of every dependency. A crafted package that makes permlock miss a power, report the wrong file, crash, or run anything is a security bug.

Report it privately through GitHub: open the Security tab of this repository and choose "Report a vulnerability". Please do not open a public issue.

You will get a reply within a week. Fixes ship in a patch release with credit, unless you ask to stay anonymous.

Known limits are listed in the README. A way around one of them that the README does not mention is worth reporting too.
